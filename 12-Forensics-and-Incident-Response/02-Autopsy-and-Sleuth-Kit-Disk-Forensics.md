# 🛠️ Autopsy & The Sleuth Kit (TSK) — Disk Forensics

> [!INFO] 📌 **Tool Metadata**
> - **Category**: Digital Forensics Hard Drive & Image Analysis Platform
> - **License**: Open Source (GPL)
> - **Installation**: Pre-installed on Kali Linux (`autopsy`, `sleuthkit`)
> - **Primary Objective**: Disk image analysis, deleted file recovery, keyword indexing, web browser history analysis, and forensic timeline creation.

---

## 💻 Practical Workflows

```bash
# 1. Start Autopsy Web Interface on Kali Linux
sudo autopsy

# 2. Access Web Interface at http://localhost:9999/autopsy
# 3. Create Case -> Add Target Disk Image (.dd, .raw, .E01) -> Run Ingest Modules -> Inspect File System
```
